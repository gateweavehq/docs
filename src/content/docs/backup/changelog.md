Notable changes to Gateweave Backup, newest first. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org). Until 1.0, any release may change how things work:
read its entry before updating your deployment. The repository format has a version of its own
([docs/format.md](/backup/format/)), and a release never changes what version 1 means.

Each version's [GitHub release](https://github.com/gateweavehq/backup/releases) carries the same
notes.

There is no release yet. Until the first, `main` is what there is, and its history says what
changed.
